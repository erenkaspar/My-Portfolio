# erenkaspar.com

Source of [erenkaspar.com](https://erenkaspar.com). The site is currently under maintenance.

## Stack

Plain HTML, CSS and vanilla JS. No build step.

## Structure

```
index.html
assets/
  styles/
    tokens.css        Design tokens (colors, type, spacing, motion)
    base.css          Reset and element defaults
    components.css    Components (BEM naming)
  scripts/
    main.js
  icons/
    favicon.svg
```

## Development

```bash
npm install
npm run dev
```

Runs on http://localhost:3200.
